# Examples

Sample specs that render with the bundled TEST images (`sample-*.png` are test artwork, not real product photos).

    node .claude/skills/brag/engine/scripts/render.mjs .claude/skills/brag/engine/examples/bevanssons-sneaker-kit-15s.json --out brag-output

`concept-luxury.json` has no product image, so it shows the DEMO placeholder product. The features in it belong to a fictional test product.
